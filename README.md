## 📖 核心特性与架构亮点

主流显示器硬件物理最低亮度普遍在 10%~20%，熄灯后依然刺眼，且普通软件滤镜容易阻碍鼠标操作或残留变色。Luna Dimmer 创新采用**双轨调光架构**：

- **🖥️ 首次启动继承屏幕，不分白夜即调即存**：
  - 软件首次启动时，**默认直接按照屏幕当前原本的真实物理亮度得来，不要手动设置，不区分白夜**；
  - 用户在任何时刻调整亮度，**立即持久化自动保存**，下次启动精准显示上次保存的亮度。
- **🛡️ 软件崩溃自愈守护（设置全部失效保证）**：
  - **如果软件崩溃了，要恢复屏幕之前的亮度和色温，软件设置的全部失效**；
  - 搭载双重崩溃防护网络：进程内全局异常拦截链（`sys.excepthook`）与独立轻量级内核事件监听守护进程（`src/crash_guard.py`）；
  - 无论是 Python 异常闪退、内存崩溃还是进程被强制结束，守护进程毫秒级感知，**强制将屏幕物理亮度和 Gamma 色温恢复至启动前初始状态，使得软件设置全部失效**，绝不残留暗屏或偏色。
- **🌓 软硬双轨调光架构**：
  - **10% ~ 100% 物理背光轨**：调用 DDC/CI I2C 硬件总线调节显示器真实背光与能耗；
  - **0% ~ 10% 穿透遮罩轨**：硬件到达临界下限后，全屏 **100% 鼠标穿透**暗夜遮罩无缝介入，比显示器最低亮度再暗一点，真正柔和护眼；
- **🟢 🟡 🔴 原生悬浮控制组**：遵循习惯，最右侧为关闭（红灯退出无痕还原）、中间为最小化（黄灯折叠托盘）、左侧为偏好设置（绿灯），图标默认常驻直观可见；
- **⚡ 2x 深度压暗**：流光微芯片一键翻倍暗化倍率，在相同刻度下获得极致深暗墨玉光感；
- **🎧 纯黑挂机（黑屏听歌）**：睡前挂机听歌、播客、下载，一键进入 99.5% 极限黑屏（电脑不关机、屏幕不关电源），晃动鼠标以 1.5 秒三次贝塞尔慢速优雅苏醒，防强光刺激；
- **🕯️ 琥珀色温（Night Shift）**：1800K ~ 6500K 烛光色温调节，柔和过滤刺眼蓝光；
- **🛡️ 退出绝对无痕还原**：退出软件时 100% 自动还原系统原生态屏幕硬件亮度与色温，绝不污染系统注册表与色彩文件；
- **⌨️ 1% 方向键微调与重置**：支持键盘 `←` / `→` 方向键 1% 精细步进，面板常驻 `[ ↺ 重置 ]` 按钮；
- **💻 全版本 Windows 原生兼容 (Win7 / Win10 / Win11, 32位 / 64位)**：底层 Win32 API 基于系统版本与指针位宽智能自适应，Windows 7 自动回退 YaHei 字体与平滑软件遮罩兜底，Windows 10/11 启用高 DPI 与原生硬件背光控制，纯原生极低资源占用。

## 🏗️ 大厂整洁分层架构 (Clean Layered Architecture)

为了避免项目代码膨胀演变成难以维护的「上帝对象（God Object）」，Luna Dimmer 全面采用大厂分层解耦架构，严格隔离核心算法、系统底层与展现层。开发者**无需通读全局代码，即可按图索骥进行精准修改与扩展**：

```text
LunaDimmer/
├── index.html                   # 官方 Web 门面：首屏左侧 1:1 Windows 原生控制面板 + 月光主题
├── version.json                 # 云端版本清单（发布时需与 CURRENT_VERSION 完全一致）
├── web/                         # 纯静态前端解耦工程 (css/, js/, assets/)
└── src/                         # 核心 Python 应用程序
    ├── main.py                  # 启动入口 / 托盘常驻 / 崩溃守护子进程入口
    ├── core/                    # [领域核心层] 双轨调光引擎、穿透遮罩、崩溃守护、原子持久化
    ├── platform/                # [平台适配层] Win32 API、多显示器 Gamma、全局热键消息泵
    ├── services/                # [通用服务层] i18n 引擎、异步版本检测
    ├── styles/                  # [设计资产层] ThemeTokens 代币 + 应用图标绘制
    ├── widgets/                 # [原子控件层] 滑块/开关/分段器/胶囊 HUD 的真实实现
    ├── ui/                      # [用户界面展现层] 主悬浮面板、弹窗与设置中心
    │   ├── dialogs/settings/    # 设置中心解耦微模块 (通用/光学/快捷键/安全重置)
    │   └── widgets/             # 控件兼容门面（全部转发到 src/widgets/）
    └── [Facades]                # 根目录门面兼容层 (100% 保持旧调用向后兼容)
```

> **版本号唯一来源**：`src/services/updater.py` 的 `CURRENT_VERSION`。发版时只需改这一处，
> 并同步根目录 `version.json`；界面、托盘提示、反馈 UA 与对外下载链接都会自动跟随，禁止再硬编码 `V1.0.0`。

> **网页端首屏规范**：打开 `index.html` 第一屏即为「左侧 1:1 还原 Windows 原生高刷微晶控制面板」，
> 面板尺寸严格为 474 × 608（446 × 576 卡片 + 外窗留白），拖拽 / 滚轮 / 键盘 / 纯黑挂机全部可玩；
> 样式权威文件为 `web/css/luna.css`，主题三态（深色 / 浅色 / 液态玻璃）由 `window.currentWebTheme` 统一驱动。

## 🚀 用户运行与构建方式（由用户自主执行）

> **全部步骤由用户手动执行**

### 方式一：Python 源码运行

1. **安装运行依赖**：
   ```bash
   pip install -r requirements.txt
   ```

2. **启动程序**：
   双击根目录下的 `run.bat`，或者在终端执行：
   ```bash
   python -m src.main
   ```
   *(或直接执行 `python src/main.py`)*

---

### 方式二：用户自主一键打包 Exe

如需根据最新代码生成单文件独立可执行程序：
- 直接双击根目录下的 **`build_exe.bat`**；
- 脚本会自动调用 PyInstaller 进行单文件打包，并将生成好的 `LunaDimmer.exe` 自动部署至项目根目录。

## ⌨️ 常用快捷键

| 快捷键 | 动作 | 说明 |
|---|---|---|
| `Ctrl + Alt + Up / Down` | 增减亮度 | 步长 5%，平滑无级调节 |
| `Ctrl + Alt + S` | 助眠极暗 | 睡前摸黑一按即可，直降至 5% 舒适微光 |
| `Ctrl + Alt + B` | 纯黑挂机 | 听歌/播客专用，99.5% 纯黑屏，晃动鼠标苏醒 |
| `Ctrl + Alt + L` | 呼出/隐藏面板 | 快速切换托盘控制卡片显示与隐藏 |
| `Ctrl + Alt + Backspace` | 紧急还原唤醒 | 防误触急救，一键直达 100% 原生系统亮度 |
| `← / → 方向键` | 1% 微调 | 获得最精确的细腻光感步进 |
